## What I Learned
- Learned what arrays are and how to store multiple values in one variable.
- Learned how to access array elements using an index.
- Learned how to create and initialize one-dimensional arrays (1D arrays).
- Learned how to create and use two-dimensional arrays (2D arrays) with rows and columns.

- Learned that an array has a fixed size that cannot be changed after it is created.
- Learned how to store and access different types of information, such as product names and product types, in a 2D array.
