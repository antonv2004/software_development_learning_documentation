## Why C#
My first programming language for software development will be C#. I chose C# because it is not too hard for beginners, it has a large open-source developer platform (.NET) with a lot of frameworks, and it is cross-platform.

## Development and learning environment  
- MacOS
- JetBrains Rider
- Programmieren Starten C# Masterkurs (German C# course)

I found out that Visual Studio for Mac stopped receiving updates in 2024. So I had two choices: Visual Studio Code and JetBrains Rider. I chose JetBrains Rider because it has many useful features for C# and .NET development. For example,It  has a built-in debugger, which allows me to run my code step by step and check the values of variables. Rider also supports unit testing and Git, so I can manage my tests and version control in one place.
I had an old C# course that I bought back in 2020, so i decided to reuse it.
