## What I Learned
- Learned what type conversion is and why it is used in C#.
- Learned the difference between implicit and explicit conversion.
- Learned that implicit conversion happens automatically when data loss can be avoided.
- Learned that explicit conversion uses a cast operator, such as (float), when automatic conversion is not possible.
- Learned that converting from double to float can cause a loss of precision.
- Learned how to use the Convert class to convert between data types, for example with Convert.ToSingle().
